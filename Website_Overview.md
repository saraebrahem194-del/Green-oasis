# Green Oasis — HTML/CSS/JavaScript version

A front-end learning project for an imaginary plant store
Built with HTML, CSS, and JavaScript to practice responsive design, modern UI/UX principles, and interactive components

This is the standalone version of the Green Oasis storefront. It uses only:

- `index.html`
- `style.css`
- `script.js`

There is no React, Vite, framework, database, or build step.

## Run it

### Easiest option

Double-click `index.html` to open it in a browser.

### Recommended option

Open the folder in Visual Studio Code and use the Live Server extension, or run any local static server:

```bash
npx serve .
```

## Included interactions

- Hide-on-scroll/show-on-scroll navigation
- Category filtering
- Favorites
- Add-to-basket actions
- Cart drawer with subtotal and remove actions
- Mobile navigation
- Newsletter feedback
- Responsive layouts
- Scroll reveal animations
